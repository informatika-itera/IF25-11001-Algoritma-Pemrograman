# Latihan Pertemuan 11: Searching

Latihan bertingkat untuk fase Latihan (20 menit) Pertemuan 11 Algoritma Pemrograman (IF25-11001, ITERA). Materinya ada di slide `01 Slide/P11 Searching.pdf` dan modul `03 Modul/Modul 11 - Searching.pdf`.

## Capaian

| Sub-CPMK | Kemampuan |
|---|---|
| 11.1 | Merancang pseudocode linear search (termasuk hasil tidak ditemukan dan semua kemunculan) dan binary search pada data terurut |
| 11.2 | Menelusuri binary search dengan trace table low, high, mid, membandingkan banyak perbandingan kedua algoritma, dan menjelaskan syarat data terurut |

## Cara mengerjakan

Cetak `Lembar Latihan P11.pdf` atau salin soalnya ke kertas. Semua soal dikerjakan dengan pseudocode dan trace table, tanpa komputer. Tulis nilai $A$ (digit terakhir NIM, kalau 0 pakai 5) dan $B$ (digit kedua dari belakang, kalau 0 pakai 3) di bagian atas. Kerjakan berurutan dari tingkat 1, dan beri satu kalimat alasan di setiap langkah.

## Aturan

Diskusi dengan teman boleh, tetapi tulisan milik sendiri. Kalau macet lebih dari tiga menit, buka lagi contoh lengkap di slide atau modul. AI boleh dipakai untuk memeriksa di rumah, tidak untuk menggantikan trace yang harus kalian tulis sendiri. Latihan tidak dinilai langsung; yang dinilai adalah presentasi papan dan Exit Ticket 11.
