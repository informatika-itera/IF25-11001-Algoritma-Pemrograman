# Simulasi UTS Pertemuan 7

`Lembar Simulasi UTS P7.pdf` berisi lima soal dengan bentuk dan bobot UTS. Kerjakan di rumah dalam 120 menit dengan satu lembar A4 ringkasan tulisan tangan, tanpa membuka slide atau modul. Soal simulasi 60 menit yang dikerjakan di kelas, kuncinya, dan kunci lembar simulasi ada di folder `kunci/` yang dipegang tim pengajar dan tidak ikut di repo.
