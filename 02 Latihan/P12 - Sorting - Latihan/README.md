# Latihan Pertemuan 12: Sorting

Latihan bertingkat untuk fase Latihan (20 menit) Pertemuan 12 Algoritma Pemrograman (IF25-11001, ITERA). Materinya ada di slide `01 Slide/P12 Sorting.pdf` dan modul `03 Modul/Modul 12 - Sorting.pdf`.

## Capaian

| Sub-CPMK | Kemampuan |
|---|---|
| 12.1 | Merancang pseudocode bubble sort dan selection sort untuk mengurutkan naik maupun turun, termasuk dua array sejajar |
| 12.2 | Menelusuri isi array sesudah setiap putaran, menghitung perbandingan dan penukaran, dan menjelaskan mengapa keduanya tergolong $O(n^2)$ |

## Cara mengerjakan

Cetak `Lembar Latihan P12.pdf` atau salin soalnya ke kertas. Semua soal dikerjakan dengan pseudocode dan trace table, tanpa komputer. Tulis nilai $A$ (digit terakhir NIM, kalau 0 pakai 5) dan $B$ (digit kedua dari belakang, kalau 0 pakai 3) di bagian atas. Kerjakan berurutan dari tingkat 1, dan beri satu kalimat alasan di setiap langkah.
