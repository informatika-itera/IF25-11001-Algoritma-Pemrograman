# Latihan Pertemuan 9: Array Satu Dimensi

Latihan bertingkat untuk fase Latihan (20 menit) Pertemuan 9 Algoritma Pemrograman (IF25-11001, ITERA). Materinya ada di slide `01 Slide/P9 Array Satu Dimensi.pdf` dan modul `03 Modul/Modul 09 - Array Satu Dimensi.pdf`.

## Capaian

| Sub-CPMK | Kemampuan |
|---|---|
| 9.1 | Merancang pseudocode yang menyimpan data sejenis di array satu dimensi dan memprosesnya dengan traversal: total, rata-rata, maksimum beserta indeksnya, dan counting |
| 9.2 | Menelusuri isi array dengan trace table, menghitung alamat elemen, dan menjelaskan kesalahan indeks termasuk akses di luar batas |

## Daftar soal

| Tingkat | Waktu | Soal | Yang dilatih | Sub-CPMK |
|---|---|---|---|---|
| 1, Dasar | 5' | 1.1, 1.2 | membaca isi array dan menghitung alamat elemen | 9.2 |
| 2, Menengah | 8' | 2.1, 2.2 | pseudocode total, rata-rata, minimum beserta indeksnya | 9.1 |
| 3, Tantangan | 7' | 3.1 | menemukan dan menjelaskan kesalahan indeks | 9.2 |
| Pengayaan | sisa | P | membalik array di tempat | 9.1 |

## Cara mengerjakan

Cetak `Lembar Latihan P9.pdf` atau salin soalnya ke kertas. Semua soal dikerjakan dengan pseudocode dan trace table, tanpa komputer. Tulis nilai $A$ (digit terakhir NIM, kalau 0 pakai 5) dan $B$ (digit kedua dari belakang, kalau 0 pakai 3) di bagian atas. Kerjakan berurutan dari tingkat 1, dan beri satu kalimat alasan di setiap langkah.
